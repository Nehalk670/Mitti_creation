# Product Images

Place your product images in this directory with the following filenames:

## Required Images:
- `golden-diya.jpg` - Golden Diya product image
- `ceramic-lantern.jpg` - Ceramic Lantern product image
- `crystal-candle.jpg` - Crystal Candle Set product image
- `floating-diyas.jpg` - Floating Diyas product image
- `hanging-lanterns.jpg` - Hanging Lanterns product image
- `silver-diya.jpg` - Silver Diya Collection product image
- `lotus-candle.jpg` - Lotus Candle Holder product image
- `copper-lantern.jpg` - Copper Lantern Set product image

## Image Requirements:
- Format: JPG, PNG, or WebP
- Recommended size: 800x800px or larger
- Aspect ratio: Square (1:1) preferred
- Quality: High resolution for product display

## How to add images:
1. Copy your product images to this `public/images/` directory
2. Rename them to match the filenames above
3. Restart the server if needed
4. The images will be served at: `http://localhost:5000/images/filename.jpg`
